# Stellar Landing Page

Stellar is a premium, interactive landing page for a creative agency. Built with React and Vite, it leverages Tailwind CSS, GSAP animations, and Three.js for immersive 3D web experiences.

## Tech Stack
- **React** & **Vite**: Core framework and fast build tool.
- **Tailwind CSS**: Utility-first styling.
- **GSAP**: High-performance scroll animations and custom cursors.
- **Three.js**: Interactive 3D elements, particle systems, and WebGL scenes.

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```
